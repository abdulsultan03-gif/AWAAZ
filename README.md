# Awaaz TTS (Asad / Uzma) — Android system TTS engine

Phone ka text-to-speech engine jo Microsoft ki Urdu voices (ur-PK-AsadNeural, ur-PK-UzmaNeural) use karta hai.
Internet chahiye.

## APK banane ka tareeqa (GitHub Actions, free)
1. GitHub par naya repository banao (e.g. `awaaz-tts`).
2. Is folder ki saari files upload karo (`.github` folder samet).
   PC par: repo page > Add file > Upload files, poora folder drag-drop.
3. Repo ke **Actions** tab me "Build APK" run hone do (3-5 minute).
4. Run khol kar neeche **Artifacts** se `Awaaz-TTS-APK` download karo, zip kholo, `app-debug.apk` install karo.

## Phone me set karna
Settings > Text-to-speech output > Preferred engine > **Awaaz TTS (Asad)**.
Voice Asad default hai. Uzma app ke Test button se check kar sakte ho.
